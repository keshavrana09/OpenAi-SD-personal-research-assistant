Personal Research Assistant

🔍 Functionality:
The user enters a query, and the assistant searches Google using the Serper API to retrieve the most relevant results. It then summarizes the key insights using the OpenAI SDK and displays the findings through an interactive Gradio interface.

⚙️ Technologies Used:

Serper API – for real-time Google search data

OpenAI SDK – for summarization and natural language understanding

Gradio – to create a user-friendly web interface

Python – for backend processing and integration
